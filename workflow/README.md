# Workflow Tasarımları

Bu klasörde kurum içerisinde kullanılabilecek örnek iş akışları yer almaktadır.

## Workflow 1 – Teknik Rapor Hazırlama

```text
Konu Belirleme
      │
      ▼
Bilgi Toplama
      │
      ▼
Claude ile Taslak Oluşturma
      │
      ▼
İnsan Kontrolü
      │
      ▼
Son Düzenleme
      │
      ▼
PDF / DOCX Teslimi
```
