# XML Yapılandırılmış Prompt

## Prompt

```xml
<role>
Siber güvenlik analisti olarak görev yap.
</role>

<context>
Ubuntu sunucusunda güvenlik incelemesi yapılmaktadır.
</context>

<task>
Güvenlik bulgularını önem derecesine göre değerlendir.
</task>

<constraints>
Kesin olmayan bilgileri gerçekmiş gibi sunma.
</constraints>

<output_format>
Markdown tablo oluştur.
</output_format>
```

## Amaç

Prompt içerisindeki görevleri düzenli biçimde ayırmak.

## Beklenen Sonuç

Markdown biçiminde risk analizi tablosu oluşturulması.
